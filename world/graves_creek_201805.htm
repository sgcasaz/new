Graves Creek

May 2018

One evening after Eric got off of work, we decided to take a drive up to the Graves Creek area to see how it looked after last year's fires.  It was surprisingly still beautiful after all that destruction, so we were very thankful for that.  This is a beautiful area so close to Eureka so it is a blessing that it is still a nice place to go.
